# Fotos originais

Estes arquivos NAO vao para o site. Sao a fonte: o build gera a partir deles
as versoes leves em WebP (`src/assets/*.webp`, que as paginas importam) e as
imagens de compartilhamento (`public/og/*.jpg`).

Ao trocar ou adicionar uma foto: coloque o JPG aqui e rode

    npm run images

Nunca edite `src/assets/*.webp` na mao - ele e regerado e sobrescrito.
